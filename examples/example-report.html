03 — Caveats

Reading this honestly

Five things that would make the numbers say something they do not say.

1 cell(s) are not measurable and are excluded from every total on this page.

Cost and accuracy on this page are computed from different documents, because the two need different requests: the cost figures come from 17 document(s) asked for one shared schema, so a payload difference is attributable to the document, and the accuracy figures from 17 document(s) asked for their answer key's own fields, which is what makes them scoreable. Neither set's token counts are comparable with the other's, and nothing on this page compares them.

01

The delta is not waste

The “without Nutrient” calls return no reliable page coordinates. They are cheaper because they do less: no grounded source locations, no confidence components. Do not read the delta as waste.

02

Output tokens are not comparable

Output tokens are not comparable between the two halves. The SDK asks for grounded metadata the direct call does not, and a direct call is free to be verbose — in one measured run a single document's direct call emitted about 7,500 more output tokens than its SDK counterpart, which alone was enough to flip the aggregate and make the SDK look cheaper overall. The headline figure is therefore priced from input tokens, which measure the same document on both sides. The total including output is shown separately and should not be read as a like-for-like saving.

03

Tokens do not compare across providers

Token counts are not comparable across providers — each tokenises the same document differently, so a cross-provider token column compares tokenizers rather than efficiency. Compare tokens within a provider, and cost across them.

04

Thinking tokens are billed as output

Anthropic bills thinking tokens inside output tokens, itemised separately in its usage block. Output cost is not proportional to returned text.

05

Read this before quoting a figure

This report combines measurements from more than one separate run, listed under Run above. Each figure is exact for the run it came from, but the runs happened at different times and may have used different credentials or a different machine, so treat a comparison ACROSS models as close to like-for-like rather than exactly so.

On the prices used

Rates are per million tokens, in USD, at published list prices, each read off the vendor's own pricing page on the date above. Claude Sonnet 5 is $2/$10: the introductory rate announced through 2026-08-31 is now the standard price and the scheduled increase to $3/$15 was cancelled, so an earlier version of this table overstated Anthropic by 50%. OpenAI's gpt-5.4 is the STANDARD tier under 272K context; the Batch and Flex tiers are half that and Fast Mode is double, and this tool makes ordinary synchronous calls. Bedrock is partner-priced by AWS and is NOT interchangeable with Anthropic first-party rates; the figures here are US East, and other regions differ (Asia Pacific Sydney is $0.5459/$2.7398). Cached input is cheaper than fresh input at every vendor and this table does not model it, so a run that hits a cache costs less than reported, never more. A local runtime has no per-token price at all — its cost is hardware and electricity, which this tool does not attempt to model, and it is reported as not priced rather than as free. Override with --prices to use your negotiated rates.
